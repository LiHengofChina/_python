//====================================== 和 Token、Embedding 的关系


你写的 Prompt（文本）
    → Tokenizer 切成 Token
    → Embedding 变成向量
    → Transformer 计算
    → 模型回复（也是一个个 Token 生成出来）


Prompt 是入口；怎么写，直接影响输出质量。


/**
你写的 Prompt 先被切成 Token，
再经 Embedding 变成 词向量（向量），
之后 Transformer 才拿这些向量去算；
模型回复也是一个个 Token 再拼回文字。
*/


//====================================== 和「上下文窗口」的关系
//====================================== 和「上下文窗口」的关系


上下文窗口 = 容器（一次最多装多少 token）
Prompt     = 往里装的内容之一（怎么写、写什么）


注意：窗口里往往不止当前这一句 Prompt，
还有 System、历史对话、贴进去的文档/RAG、以及模型输出——都占额度。
