

//====================================== 一句话
//====================================== 一句话


Prompt（提示词）：你给大模型的 "输入指令/问题"，
				  模型根据它 "生成回答"。


Prompt = 你怎么跟大模型说话（可含角色、任务、约束、格式要求）
		 写得好，回答才准。


//====================================== Prompt 例子
//====================================== Prompt 例子


（1）「把下面日志总结成 3 条」→ Prompt
（2）「你是运维助手，分析这段报错」→ Prompt //（带角色设定）


//====================================== 和「聊天输入框」的关系
//====================================== 和「聊天输入框」的关系


日常在 ChatGPT / Cursor 里打的那 "一大段文字"，
本质上就是 Prompt。
"工程里" 也可以是 "代码拼出来的字符串（模板 + 变量）"。
