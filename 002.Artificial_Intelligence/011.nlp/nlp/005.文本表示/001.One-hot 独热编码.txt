//===================================================== One-hot 独热编码

//========================== 示例
//========================== 示例

减肥：[1, 0, 0, 0, 0]
瘦身：[0, 1, 0, 0, 0]
增重：[0, 0, 1, 0, 0]
塑性：[0, 0, 0, 1, 0]
降脂：[0, 0, 0, 0, 1]

//用长度为5的向量表示5个词

//========================== 缺点
//========================== 缺点

（1）"瘦身"  和 "增重"  语义完全相反，
	 余弦相似度是 0 、欧氏距离是 √2，所以但是它们 "不能表示语义相似度"。
	 互相垂直、看不出语义，
	 词语之间的相似度、相关程度无法度量。

（2）表达 "效率" 比较差，
	 它是 "稀疏矩阵"，"长度为5的向量" 表示 "5个词"，
	 "长度为100万的向量" 才能表示 "100万个词"，有多少词就需要多大的向量。

//========================== 使用场景
//========================== 使用场景

当作「整段文本的表示」已经很少了，被词嵌入/BERT 替代。

还在用的场景：
（1）表格特征里的类别（性别、城市）仍常 One-hot
（2）模型内部：词表 id → 查 embedding，本质仍是「第 i 个词对应第 i 维」
