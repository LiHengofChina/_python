//====================================== 一句话

上下文窗口：模型一次最多能看多少 token（容量）。
常见说法：4K、8K、32K、128K、1M……

（K ≈ 1024 个 token）

//token 是指 切出来的最小单位（字/词/子词）对吧

//====================================== 和 Token / Embedding 的关系
//====================================== 和 Token / Embedding 的关系

（1）Token：文本切成的小单元，是模型输入单位（多少个token）

（2）Embedding：每个 token 变成向量，才能进 Transformer

（3）上下文窗口：一次最多处理多少个 token 的上限

Token 是输入单位，

Embedding（词向量）是进 Transformer 的格式，

上下文窗口是 Transformer 一次能处理的 Token 上限。
