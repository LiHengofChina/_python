
//======================================================== Token 与 词向量
//======================================================== Token 与 词向量

Token 是 "文本" 切出来的 "最小单位"（字/词/子词）；

词向量：是每个 token 对应的一串数字（向量）。

//======================================================== 它们的关系
//======================================================== 它们的关系

关系：先有 token，
	再把 "每个 token" 查表/映射成词向量，
	//模型实际算的是这些向量，不是原始文字。

补一句：中间常有一步「token → 数字 id」，
	id 再进 Embedding 表，才变成词向量。

/**

差别只是：字符集偏标准编码；这里的词表是某个模型/分词器自己的，
		  而且 id 之后还要再进 Embedding 变成向量。
