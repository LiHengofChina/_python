

//======================================================== Token 与 大模型
//======================================================== Token 与 大模型


Token	//文本切成小单元，是模型输入单位

Token = 把文本切成模型能处理的小单元（字、词、子词都行），是最基础的切分。





大模型一般只做 Tokenization，不做词性标注。

这里的 Tokenization（常按子词）≠ 传统 jieba 那种「按词切 + 词性」；大模型管线一般只要前者。


分词、词性标注是传统 NLP 的额外步骤。
