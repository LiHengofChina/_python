//============================================= 不要混为一谈
//============================================= 不要混为一谈

「部署大模型」和「部署传统 NLP 工具」不是一回事。


//============================================= Ollama（大模型）
//============================================= Ollama（大模型）

用途：跑开源大语言模型（如 Qwen、Llama、DeepSeek 等）
能力：对话、生成、按提示完成任务（Agent 里当「大脑」）
部署：用 Ollama（或 vLLM 等）加载权重，对外提供 API


//============================================= HanLP 等（传统 NLP）
//============================================= HanLP 等（传统 NLP）

用途：分词、词性、NER、依存等结构化 NLP
能力：偏「分析文本结构」，不是通用大模型对话
部署：HanLP 2.X 用自己的模型与启动方式，不能靠 Ollama 来部署


//============================================= 怎么配合用
//============================================= 怎么配合用

可以同机各跑各的：
	一边 Ollama 提供 LLM API
	一边 HanLP 提供分词 / NER

业务里按需调用，不要指望「装了 Ollama 就等于装了 HanLP」。
