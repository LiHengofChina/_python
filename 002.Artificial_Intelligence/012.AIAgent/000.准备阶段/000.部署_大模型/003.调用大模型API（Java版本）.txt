//============================================= 前提
//============================================= 前提

先在本机或内网把 Ollama 装好，并拉取好模型（见 001.Ollama）。
Java 侧本质就是：向 Ollama 的 HTTP 地址发请求。

默认端口常见为：11434


//============================================= 方式一：兼容 OpenAI 的接口（最常用）
//============================================= 方式一：兼容 OpenAI 的接口（最常用）

地址一般是：

	http://主机:11434/v1/chat/completions

请求体用 JSON，主要字段：

	model      模型名（与 ollama list / pull 的名字一致）
	messages   对话列表（role + content），和调 OpenAI 类似

Java 里可用：

	（1）Spring：RestTemplate / WebClient
	（2）OkHttp、Apache HttpClient
	（3）OpenAI 官方 Java SDK：
		把 baseUrl 设成 http://主机:11434/v1
		apiKey 若服务端不校验，可随便填一个占位字符串


//============================================= 方式二：Ollama 原生接口
//============================================= 方式二：Ollama 原生接口

例如：

	POST http://主机:11434/api/chat

body 里同样有 model、messages 等，字段名与 OpenAI 略有差异，
以 Ollama 官方 API 文档为准。


//============================================= 注意
//============================================= 注意

（1）主机填 127.0.0.1 / localhost，或内网 IP（如 192.168.x.x）
（2）防火墙要放行 11434（跨机器调用时）
（3）model 名写错会直接报找不到模型；先用命令行 ollama list 确认
